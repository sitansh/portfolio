RESUME FILE SETUP INSTRUCTIONS
================================

To complete the resume download functionality:

1. Create or export your resume as a PDF file named "Full_Stack_Resume.pdf"
2. Place the PDF file in the root directory of this portfolio project
   (same location as index.html)
3. The download button will automatically work once the PDF is in place

The download button is configured to:
- Look for: Full_Stack_Resume.pdf
- Download as: Sitanshu_Shekhar_Resume.pdf (the name users will see)

You can use any PDF editor or export from Word/Google Docs to create your resume PDF.

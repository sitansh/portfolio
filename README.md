# Portfolio

Simple static portfolio site.

This repository contains a single-page portfolio website. It is a lightweight static project intended to be opened in a browser or served from any static hosting provider.

## Features

- Static HTML site: `index.html`
- Easy to host on GitHub Pages, Netlify, or any static server
- Minimal dependencies

## Files

- `index.html` — The main and only page of the site.

## Quick Start

Option 1 — Open locally:

1. Double-click `index.html` or open it in your browser.

Option 2 — Serve with Python (recommended for consistent behavior):

```powershell
# Python 3
python -m http.server 8000; Start-Process 'http://localhost:8000'
```

Option 3 — Serve with Node (if you have Node.js):

```powershell
npx serve .
```

Then open `http://localhost:8000` (or the address printed by the server).

## Development

- Edit `index.html` to update content.
- Use your preferred editor; no build step is required.
